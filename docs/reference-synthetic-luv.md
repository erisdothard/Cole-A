## What this adds that Johnny Mnemonic did not

1. **A literal storyboard for the entry.** footage → reveal it is a CRT → hand on keys → pulse down the cable → flare → grid → inside. Johnny Mnemonic gave the tunnel; this gives the *physical machine* and the *cause-and-effect* of turning it on.
2. **The inside is a lattice of computers, not a HUD.** Combine: you fly the lattice (this video) and each node opens a HUD panel (Johnny Mnemonic window grammar).
3. **Monochrome duotone discipline.** Everything — footage, hardware, CG, type — is forced through one hue. That is what makes wildly different source material feel like one world, and it solves a real problem for this site: Cole's posters are every colour at once. Thumbnails/nodes in duotone, full colour only when a piece is opened.
4. **Texture is phosphor-grid and dither, not just scanlines.** Dot-pitch moiré on the glass, ordered dithering on images, tear bars on transitions.

## Reconciling the two palettes

Johnny Mnemonic is blue/cyan/violet with red interrupts; this is all magenta. Both are valid for CVZ (his logo clip is neon blue). Working proposal for the design spec: the system runs in **one duotone at a time** — blue by default (matches the CVZ neon mark) — and the hue is a system setting the viewer can flip (magenta, green, amber), like swapping a monitor's phosphor. Needs Cole's sign-off; he may simply want pink.
